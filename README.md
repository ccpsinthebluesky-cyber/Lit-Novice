# AI協助工具：文學小白便利貼（Lit-Novice）

> **核心定位速讀：**

## 一、這是什麼工具？

現代大型語言模型普遍採用位元組對編碼（BPE）分詞機制，在無空格的中文語境中，常造成詞塊黏合、跨詞搶字、古典單字語素遭現代高頻詞吞噬，以及標點符號「裝飾化」失靈。

**文學小白便利貼（Lit-Novice）** 依據 Unicode 換行規範（UAX #14）與 W3C 中文排版需求（CLReq），於中文漢字與標點縫隙精準配置：
- **分隔符（`U+200B` Zero Width Space）**：解除 BPE 詞塊沾黏，恢復逐字解析精度。
- **連接符（`U+2060` Word Joiner）**：將標點自前詞剝離定錨，並於視窗自動換行時達成中文標點「避頭尾」排版效益。
- **自動豁免**：原文全形／半形空白、換行、連續英數與半形網址一律原封不動跳過。

## 二、30 秒跨模型即時實測

只要主流大型語言模型仍仰賴子詞壓縮分詞控管算力成本，本方法即具備跨平台、零門檻的即時可重現性。請直接複製以下《還陽》春暉篇首句之雙版本，分別以純文字貼入任意主流 AI 對話框，即可現場驗證差異：

- **未處理版**：`神風橫掃天雷現`
- **已處理版**：`神​風​橫​掃​天​雷​現`（內含 6 顆 `U+200B` 分隔符）

## 四、程式碼快速呼叫

### Python
```python
from lit_novice import apply_lit_novice, remove_lit_novice

raw = "神風橫掃天雷現"
enhanced = apply_lit_novice(raw)      # 植入隱形空白
restored = remove_lit_novice(enhanced) # 一鍵還原
```

### JavaScript
```javascript
const raw = "神風橫掃天雷現";
const enhanced = applyLitNovice(raw);      // 植入隱形空白
const restored = removeLitNovice(enhanced); // 一鍵還原
```
